# HB-2026-002
## Date Completed: August 14, 2026
## Priority:  High
## Category: Account Access / Password Reset

### Problem: 
A user got back from a 3-week vacation and her previous password wouldn’t let her in log in. it was saying expired password, and she had to change it, but she couldn’t change it from the login screen.

### Troubleshooting Process: 
1.	Navigated to the company Directory containing all user accounts
2.	Located the user’s account
3.	Initiated the identity verification process
4.	Sent a verification code to the user
5.	Confirmed the user’s identity after the verification code was successfully provided
6.	Reset the user’s password and generated a temporary password
7.	Provided the temporary password to the user so they could regain access and create a new password

### Resolution: 
The user’s expired password was reset after successfully identity verification. The user was provided with a temporary password and instructed to create a new password upon logging in. 

### Status: 
Resolved
