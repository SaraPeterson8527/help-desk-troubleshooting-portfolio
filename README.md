# Help Desk Troubleshooting Portfolio

## About This Portfolio
This portfolio documents my hands-on practice with IT help desk and technical support scenarios. I am using simulated service desk tickets to develop and demonstrate practical troubleshooting, problem-solving, documentation, and user support skills. 
Each completed scenario is documented from the initial problem through the troubleshooting process and final resolution. My goal is to build experience with realistic IT support situations while developing a consistent and professional approach to troubleshooting.
This portfolio is an ongoing project and will continue to grow as I complete additional scenarios and expand my technical skills. 

## Objectives
- develop practical help desk and IT support skills
- practice troubleshooting realistic technical issues
- improve technical documentation and ticket writing
- develop a structured approach to problem solving
- practice user account and access management
- strengthen security-conscious troubleshooting practices
- build experience with common it support tools and technologies
- document hands-on experience for future IT support and cybersecurity roles

## Resources Used
### ServiceDesk Simulator
The primary resource used for the simulated help desk scenarios is ServiceDesk Simulator.
ServiceDesk Simulator provides hands-on IT support scenarios designed to simulate realistic help desk environments. The platform includes scenarios involving password resets, network troubleshooting, software installations, Active Directory user management, Remote Desktop support, and other common IT support tasks. 
#### Website: https://servicedesk-simulator.com
I use the simulator as a practice environment to develop my troubleshooting skills and then document my approach and results independently in this portfolio.
